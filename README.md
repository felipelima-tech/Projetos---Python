Sistema de Compras com Descontos e Formas de Pagamento

Este projeto foi desenvolvido em Python como parte dos meus estudos em lógica de programação.

O objetivo foi simular um sistema simples de compras, permitindo o cadastro de um cliente e de um produto, o cálculo automático do valor total da compra e a aplicação de regras de negócio relacionadas a descontos e formas de pagamento.

Durante o desenvolvimento, busquei praticar a construção de uma lógica organizada, utilizando estruturas condicionais para representar situações comuns encontradas em sistemas comerciais.

Funcionalidades
Cadastro de cliente.
Cadastro de produto.
Cálculo automático do valor da compra.
Aplicação de desconto por cupom.
Desconto adicional para pagamentos via Pix.
Acréscimo de taxa para pagamentos via Cartão.
Exibição do valor final da compra.

Conceitos aplicados
Variáveis
Entrada de dados
Operações matemáticas
Estruturas condicionais
Manipulação de strings
Formatação de valores monetários
