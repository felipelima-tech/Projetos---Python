Sistema de Compras com Descontos e Formas de Pagamento

Projeto desenvolvido em Python para praticar lógica de programação, entrada de dados, condicionais e operações matemáticas. O sistema simula uma compra em um mercado, calculando o valor total dos produtos, aplicando desconto por cupom e ajustando o valor final conforme a forma de pagamento (Pix ou Cartão).

Funcionalidades
Cadastro do cliente
Cadastro do produto
Cálculo do valor total da compra
Aplicação de cupom de 10% de desconto
Desconto adicional de 5% para pagamento via Pix
Acréscimo de 2% para pagamento via Cartão
Exibição do valor final formatado em reais
Conceitos praticados
input()
int e float
Operações matemáticas
if, elif e else
Manipulação de strings (lower() e strip())
Formatação de valores (:.2f)
